# CodexGPT

Artefacto funcional del planificador de camiones de sal.

## Ejecutar (interactivo)

```bash
npm start
```

Luego abre en navegador real:

- `http://localhost:4173`

## Nota sobre la vista previa de artefactos

La imagen de preview es solo una captura estática. Para interactuar (cambiar parámetros, añadir viajes, etc.) debes abrir la URL local con el servidor levantado.
